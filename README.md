广东茶叶货源出口海外市场的完整决策论证材料。三份报告，构成一条从「能不能做」到「怎么做」的完整链路。

## 技术说明

- **纯静态站点**：无构建步骤、无外部依赖、无 CDN。所有样式内联在各页面，仅导航样式抽到 `assets/site.css`。
- **发布方式**：GitHub Pages，Source 设为 `main` 分支根目录（`/`）。
- **响应式**：移动端自适应，甲方在手机、平板、电脑上均可正常查看。
- **可打印**：打印时自动隐藏导航与翻页器，可直接输出 PDF。
